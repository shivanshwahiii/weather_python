# Weather App (Python)

A simple weather application built with Python that fetches real-time data from the WeatherAPI.  
Implements API integration, JSON parsing, error handling, and displays current weather conditions for any city.

## Features
- Fetch current weather by city name
- Display temperature, feels-like, humidity, and condition
- Error handling for invalid city names
- Clean and interactive command-line interface
- Extensible design for adding forecasts or visualization

dependency: pip install requests


example:
=== Weather App ===
Enter city name: delhi, india
City: Delhi, India
Temp: 36.1°C
Feels like: 34.5°C
Humidity: 33%
Weather: Mist
